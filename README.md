# AI Engineering Core Track

Hands-on learning repository for **AI Engineer Core Track: LLM Engineering, RAG, QLoRA, Agents**.

- **Start date:** 2026-11-24
- **Course:** https://jpmc.udemy.com/course/llm-engineering-master-ai-and-large-language-models/
- **Goal:** Build production-ready LLM/agent engineering skills for Forward Deployed Engineering (FDE).

## Learning workflow

1. Watch a Udemy lecture.
2. Share the section/topic and personal takeaways with ChatGPT.
3. Create or refine notes in `notes/` (explain concepts, examples, trade-offs, FDE relevance, interview questions).
4. Commit runnable examples under `projects/` with appropriate instructions and tests.
5. Update `PROGRESS.md` only when work is genuinely completed.

## Repository layout

```text
AI_Engg_Core/
├── README.md              # Overview and learning workflow
├── PROGRESS.md            # Learning log and status
├── notes/                 # Section-level study notes
│   └── 00-notes-template.md
└── projects/              # Hands-on exercises (added as completed)
```

## Study principle

Learn the concept → implement it → test it → explain it → connect it to a production FDE use case.

> Notes and exercises should reflect actual lectures watched and work completed, not an assumed Udemy syllabus. Never commit API keys, tokens, or credentials.
